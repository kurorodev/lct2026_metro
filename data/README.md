# Данные для проверки Metro Guard

Metro Guard читает ROS 2 bags с облаками `sensor_msgs/msg/PointCloud2`. В репозитории есть примеры, а предоставленные архивы намеренно хранятся отдельно: это крупные данные, они не входят в публичную ссылку на код.

**Ссылки проекта:** [публичный код](https://github.com/kurorodev/lct2026_metro) · [веб-демонстрация](http://111.88.155.2/). Анализ нового сценария можно повторить по [локальной инструкции](../README.md#локальный-запуск); формат и содержание сценария описаны в [отдельной справке](../docs/NEW_DATA.md).

## Какие записи проверены

- Шесть исходных записей: 2 488 кадров суммарно.
- Новый сценарий `cloud_with_fake_obj`: 1 510 кадров и десять объектов, описанных поставщиком.
- Всего в проверках — 3 998 сообщений. Объекты размечены лишь для десяти контрольных кадров нового bag, а не для полного времени записи.

В новом сценарии LiDAR расположен в центре состава, на высоте 1,075 м над головкой рельса. Эти сведения помогают настроить геометрию, но не задают точный контур габарита, углы установки или полную трансформацию координат.

## Подготовить новый bag

Поместите полученный архив в `data/`, установите runtime-зависимости по [инструкции](../README.md#локальный-запуск), затем распакуйте:

```bash
tar --zstd -xf data/cloud_with_fake_obj.zst -C data
```

После распаковки можно запустить offline-детектор:

```bash
.venv/bin/python -m metro_guard.cli run data/cloud_with_fake_obj \
  --config config/mounted_lidar.json \
  --output outputs/cloud-mounted \
  --export-every 10 --preview-points 2000
```

Каталог bag должен содержать `metadata.yaml` и SQLite `.db3`. Свободного места нужно около 7 ГиБ. Скрипт выберет найденный `PointCloud2`-топик; если их несколько, задайте `--topic` явно.

## Проверить ROS bag в ROS 2

Для прямого воспроизведения записи потребуется ROS 2 Humble и ROS-пакеты, описанные в корневом README:

```bash
tar --zstd -xf data/for_hackathon.zst
ros2 bag play for_hackathon/doubleT_platform
```

Этот запуск только передаёт облака ROS-подписчикам; для подсчёта результатов проекта используйте CLI-команду выше. Подробности о десяти искусственных объектах — в [отчёте проверки](../docs/FAKE_SCENARIO_RESULTS.md).
