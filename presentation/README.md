# Презентация Metro Guard

`Metro_Guard_ЛЦТ2026.pptx` — 13-слайдовая презентация на основе шаблона ЛЦТ 2026. Текстовый план и пояснения находятся в [`Содержание.md`](Содержание.md), а векторные исходники слайдов — в [`source/`](source/).

Metro Guard ищет возможные препятствия в расчётном габарите пути по 3D LiDAR. Проект опубликован как [открытый код на GitHub](https://github.com/kurorodev/lct2026_metro); [веб-демонстрация](http://111.88.155.2/) показывает подготовленные результаты проекта. Запуск на своём компьютере описан в [корневом README](../README.md#локальный-запуск).

Чтобы пересобрать презентацию после правок, измените текстовый план и макеты в `scripts/build_presentation.py`, затем из корня проекта запустите:

```bash
python3 scripts/build_presentation.py
```

Слайды в PowerPoint вставлены как векторная графика SVG. В современных версиях PowerPoint её можно преобразовать в набор редактируемых фигур. На титульном слайде и слайде команды намеренно оставлены поля для состава и контактов: заполните их перед выступлением.

Ограничения качества указаны прямо в презентации: результаты сопоставления на десяти контрольных кадрах не являются оценкой precision/recall, а расчётный контур требует подтверждения владельцем пути.
